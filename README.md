# 📈 Investra – AI Powered Stock Trading Platform

Investra is a full-stack MERN-based stock trading platform designed to help users learn, practice, and explore stock market trading through both Paper Trading and Real Money Trading modes.

The platform combines modern trading features with AI-powered guidance to create an interactive financial learning experience for beginners and trading enthusiasts.

---

## 🚀 Features

### 📊 Paper Trading Mode
- Practice stock trading using virtual/demo money
- Learn trading strategies without financial risk
- Track virtual portfolio performance

### 💰 Real Money Trading
- Buy and sell stocks using real investments
- Monitor real-time portfolio activity
- Track transactions and investment growth

### 🤖 AI Chatbot Assistant
- Provides trading guidance for beginners
- Explains stock market concepts
- Helps users understand trading decisions

### 🧠 Vega AI Stock Recommendation
- Suggests trending and potential stocks
- Analyzes market behavior and stock trends
- Provides intelligent investment insights

### 📰 Market Insights
- Explains why stocks are increasing or decreasing
- Displays stock-related news and market analysis
- Helps users understand real-time market movement

### 🔐 Authentication & Security
- Secure Login & Registration
- JWT Authentication
- Google OAuth Integration
- Password Encryption using Bcrypt

### 📈 Portfolio Management
- Track investments and profits/losses
- Monitor trading history
- Manage stock holdings efficiently

### 🔍 Search & Filter
- Search stocks by company name
- Explore trending stocks
- Filter stocks based on market data

### 📱 Responsive Design
- Optimized for Desktop, Tablet, and Mobile devices
- Smooth and user-friendly interface
